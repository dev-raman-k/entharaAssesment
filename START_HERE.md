### What It Does
This is a **project management tool** where teams can:
- Create projects
- Assign tasks to team members
- Track progress
- View analytics
- Manage roles (Admin/Member)

- Dashboard with statistics

## 🎯 Your Next 3 Steps

### Step 1: Local Development (10 min)
```bash
# Backend
cd backend
npm install
npm run dev

# Frontend (new terminal)
cd frontend
npm install
npm start
```

✅ You should see the app at http://localhost:3000

### Step 2: Push to GitHub (5 min)
```bash
cd .. # Back to root
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/dev-raman-k/entharaAssesment.git
git push -u origin main
```

✅ Your code is now on GitHub

### Step 3: Deploy to Production (15 min)
1. Go to https://railway.app - Deploy backend
2. Go to https://netlify.com - Deploy frontend
3. Get your live URLs
4. Your app is live! 🎉
